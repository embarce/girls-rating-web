## 环境事故（重要）

执行层 node 崩了：**任何** Bash 调用（包括 `echo hi`、`command -v node`）都返回
`Assertion failed: (diff <= INSTR_JUMP_NE_MAX_LENGTH), function push_jne_instr, file serialize.c, line 240.`（exit 134 / SIGABRT）。
触发点：在 `/tmp/docker-sim` 跑 `pnpm install --frozen-lockfile`（先报 `ERR_PNPM_EIO [symlinkAllModules]`，随后一次带沙箱绕过的重试直接 V8 断言崩溃），之后 node 全局不可用，`grep`/`ripgrep` 等工具也随之失效，只剩文件读写工具可用。下次会话若遇到同样报错，先确认 node 能否运行，需要重启终端/环境。

## SEO 优化（技术债清理 + 可爬取性）

发现并修掉的**真问题**：
1. `public/sitemap-0.xml` 是别的项目遗留的假站点地图，列了 `/tts`、`/faceswap`、`/card` 等根本不存在的 URL（向 Google 提交一堆 404）→ 已删除。
2. `sitemap.xml` 里的 `?category=hot|latest` 是假的：代码不读该参数，三个 URL 渲染同一首页 = 重复内容 → 只保留 `/`，`lastmod` 手动维护。
3. `index.html` 有两条 `robots` meta，后者覆盖前者；`lang="en"` 与默认中文界面不符；`og-image.jpg`、`apple-touch-icon.png`、`favicon-32/16` **都不存在**（404）→ 全部补齐/修正。
4. **最严重**：`{isAged && ...}` 让 Header/main/footer 在点「进入图库」前根本不在 DOM 里，爬虫只能看到年龄门。
5. 结构化数据两处重复（index.html 三段 + App.tsx 一段）。

改法：
- **内容始终挂载**，年龄门降级为 `z-[100]` 覆盖层；未进门时给容器 `inert` + `aria-hidden` 并锁 body 滚动。实测：未点击时 DOM 里已有 12 个 `<figure>` / 12 个 `<img>`、957 字正文、1 个 h1。副作用是进门瞬间无加载态（图已预取）。
- head 重写：单条 robots（max-image-preview:large）、canonical、OG/Twitter 全量、`theme-color` 改 #0a0908、JSON-LD 合并成单个 `@graph`（WebSite/Organization/WebPage/ImageGallery），删掉组件内重复段与假 SearchAction。
- `lang` 固定 `zh-CN`，切语言时用 effect 同步 `document.documentElement.lang`。
- 标题层级：全站 1 个 h1（sr-only）；Masthead 与年龄门改 h2。
- 图片 `alt` 改成「{作者} 的 cosplay 作品 — Girls Rating」；前 6 张 eager、前 3 张 fetchPriority=high、其余 lazy + async decoding。
- `<noscript>` 做成真正可读的落地页（介绍 + 邮箱 + 子站链接）。
- robots.txt 去掉 `Host:` 与 `Crawl-delay`，加 `Googlebot-Image` 放开。
- nginx `try_files $uri $uri/ =404`，不再 SPA 回退（避免软 404 / 重复内容）。
- 用 `sips` 从 logo 生成 3 个图标；用无头 Chrome 截图 `/tmp/og/card.html` 生成 `og-image.jpg`(1200×630)。

验证：CDP 关闭 JS 检查 noscript（346 字 + h1）、开启 JS 不点门检查 DOM/head（1 个 ld+json、1 条 robots、lang=zh-CN）、进门瞬间截图确认无加载态、年龄门截图确认无内容泄露。

**任未解决**：无逐图 URL，图片 SEO 上限锁死在首页；要突破需要 SSR/预渲染或后端提供 `图片id → 独立URL`。
