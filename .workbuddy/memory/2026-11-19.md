- `AgeGate` 根节点去掉 `bg-canvas`，改 `overscroll-contain`；`closed` 态用 `bg-canvas/80 + backdrop-blur-sm`。

## 进场动画编排：撕票 → 对焦 → 推门（约 1.3s）
- `AgeGate` 点「进入」不再直接 `onAccept`：先 `leaving`（ref 防连点），票根绕左上角撕开（x34/y16/rotate3.2，340ms）、主券左移淡出、文案列各自淡出（280ms），400ms 后交接给 App。
- 之前踩的坑：把整块内容包进一个淡出层，票还没撕完就一起淡掉 → 现在只把顶部行、文案列、页脚分别包 motion，入场券独立动。
- 遮罩改成真·拉焦：`@property --gate-blur` + `.gate-veil[data-open]`，34px→0 用 820ms ease-in-out（ease-out 会读成"一键变清楚"）；scrim 延迟 140ms 淡出。`.gate-veil` 由 App 的 `gateVeil: in|opening|gone` 三态控制挂载，1300ms 后卸载。
- `<main>` 从 `scale-[1.03]` 回 1（1100ms）；注意 Tailwind v4 的 `scale-*` 走 CSS `scale` 属性，不是 `transform`。
- 抽卡弹窗延迟 1200 → 2600ms，避免压住进场。
- 验证方式：CDP 采样 `--gate-blur` 得到 34 → 20 → 0 的中间值，确认是真插值不是跳变；撕票形态用"临时放慢 10 倍 + 截图"确认后再改回。
